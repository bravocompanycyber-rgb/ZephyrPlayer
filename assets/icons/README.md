# ZephyrPlayer icons

The app already ships with a complete set (80 icons, Lucide, ISC licence, see `LICENSE-lucide.txt`).
**To use your own icon: save it in this folder with the exact name below, then alt-tab back to ZephyrPlayer — it updates live (no restart).**
Delete a file and the built-in default is used again, so nothing can ever break.

## Rules for your own icons
* Name = the name in the table, all lowercase, e.g. `play.svg`. `.svg` is preferred; `.png` also works (transparent background).
* Single colour, transparent background. The app recolours icons for dark/light themes and hover/active states
  (multi-colour icons are shown as a one-colour silhouette).
* Square, any size (24×24 viewBox is ideal). Keep each file under 200 KB.
* Open `icon-sheet.html` in your browser to see every icon with its name.

## App logo (separate from UI icons)
`logo-concept/` has a ready logo (SVG + 512 PNG + multi-size ICO + tray PNG). Your window/taskbar icon is read from
`assets/icons/zephyrplayer.ico` and the tray icon from `assets/icons/tray.png` (copy the ones you like next to this file).
For installers keep a 256×256 `.ico`. Free logo generators/editors: https://www.figma.com (Figma), https://inkscape.org, https://realfavicongenerator.net
