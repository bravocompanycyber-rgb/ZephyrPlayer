Anime4K / GLSL shaders for ZephyrPlayer
======================================

1. Download Anime4K GLSL shaders:
   https://github.com/bloc97/Anime4K/releases

2. Extract .glsl files into this folder (shaders/).

Recommended set (Mode A style):
  Anime4K_Clamp_Highlights.glsl
  Anime4K_Restore_CNN_M.glsl
  Anime4K_Upscale_CNN_x2_M.glsl
  Anime4K_AutoDownscalePre_x2.glsl
  Anime4K_AutoDownscalePre_x4.glsl
  Anime4K_Upscale_CNN_x2_S.glsl

3. In ZephyrPlayer choose Quality → Anime4K and play with mpv.

Any .glsl files placed here will be loaded if the named set is missing.
