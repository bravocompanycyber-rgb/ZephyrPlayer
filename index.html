        About ZephyrPlayer

        ZephyrPlayer 2.5.0

        Local desktop media player. No accounts. No required online APIs.

        Support
        Email: bravocompanycyber@gmail.com

        License
        Application: ZephyrPlayer License (see LICENSE.txt)
        Third-party: Electron, mpv, FFmpeg, yt-dlp — their own open-source licenses

        Privacy
        Playback, library, bookmarks, and subtitles stay on this PC. Optional tools (mpv, yt-dlp, whisper-cli) run locally.

        Windows
        Use File associations export or Default apps. Code-signing certificate can be applied when you publish a built installer.

        Subtitle style

        Applies to on-screen subs and mpv --sub-* flags when using mpv.

        Advanced audio

        Network / SMB / stream

        SMB/UNC: map drive in Windows Explorer first if needed, then paste path. DLNA: open the device URL or IPTV M3U. HLS/DASH/HTTP work via mpv + yt-dlp.

        File associations

        Creates a .reg file to register common video types with ZephyrPlayer for the current user. Review then double-click the .reg, or use Windows Default apps.
